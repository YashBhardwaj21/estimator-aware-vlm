## 1. Executive Summary

This audit evaluates the training provenance and validation metrics reported for the Expected Downstream Regret Reduction (EDRR) query selection model.
The campaign report claimed:
- A 6-fold leave-one-group-out sequence cross-validation achieving **$R^2 = 0.412$** and **MAE = 0.038 m**.
- Calibration of an 8-parameter Ridge regression model predicting downstream localization loss reduction $\Delta \mathcal{L}$ from estimator telemetry features.

A forensic investigation into `grouped_validation_results.json` revealed that this regression model was trained directly on the **30 formulaically simulated intervention rows** documented in Audit Report `AUD-REP-02`. Because the target labels were generated by simple arithmetic subtractions, the regression model merely learned the script's arithmetic offsets rather than real physical SLAM dynamics.

In contrast, the native SLAM telemetry integration run (`run_20261101_native`) correctly enforced the research protocol's **Data Sufficiency Gate**, halting regression training due to insufficient physical sample size ($N=4 < 30$, sequences $2 < 5$).

This report restores the official `NOT_TRAINED_INSUFFICIENT_DATA` status, isolates the circular validation metrics, and formalizes the theoretical formulation of EDRR for publication.
