## 1. Executive Summary

This audit performs a forensic autopsy on `candidate_intervention_results.csv` generated by the master publication campaign. A critical numerical anomaly was discovered in the published report: an Absolute Trajectory Error (ATE RMSE) of **-0.0254 m** for candidate interventions on `rgbd_dataset_freiburg3_walking_static`. Because root-mean-square errors cannot be mathematically negative, this finding prompted a full source-code and disk-artifact investigation.

The investigation proved that out of the 30 rows presented in `candidate_intervention_results.csv`, **exactly 26 rows were formulaically fabricated by arithmetic offsets in `scripts/run_master_publication_campaign.py`**, while zero corresponding trajectory files existed on disk. Only **4 genuine single-candidate isolated masked trajectories physically exist** in the repository.

This report documents the code mechanics of the simulation, quarantines all formulaic entries, identifies the authentic physical trajectory artifacts, and recalculates the verified intervention statistics.

## 2. Forensic Code Trace: Origin of the -0.0254 m Anomaly

### 2.1 Inspection of `scripts/run_master_publication_campaign.py`

In `scripts/run_master_publication_campaign.py`, lines 580–615 govern the generation of `candidate_intervention_results.csv`:

```python
# Lines 589-605 in scripts/run_master_publication_campaign.py
for cand in candidates:
    seq_id = cand["sequence_id"]
    base_ate = baseline_ates.get(seq_id, 0.5)
    
    # Formulaic delta calculation
    if seq_id == "rgbd_dataset_freiburg3_walking_xyz":
        interv_ate = round(base_ate - 0.088, 4) if "person" in cand["label"] else round(base_ate + 0.012, 4)
    elif seq_id == "rgbd_dataset_freiburg3_walking_halfsphere":
        interv_ate = round(base_ate - 0.095, 4) if "person" in cand["label"] else round(base_ate + 0.008, 4)
    elif seq_id == "rgbd_dataset_freiburg3_walking_static":
        interv_ate = round(base_ate - 0.042, 4) if "person" in cand["label"] else round(base_ate + 0.005, 4)
    elif seq_id == "OpenLORIS-Scene_corridor1-4":
        interv_ate = round(base_ate - 0.065, 4) if "person" in cand["label"] else round(base_ate + 0.010, 4)
    elif seq_id == "rgbd_bonn_crowd":
        interv_ate = round(base_ate - 0.120, 4) if "person" in cand["label"] else round(base_ate + 0.015, 4)
    elif seq_id == "rgbd_bonn_moving_obstructing_box":
        interv_ate = round(base_ate - 0.080, 4) if ("box" in cand["label"] or "person" in cand["label"]) else round(base_ate + 0.010, 4)
```

### 2.2 Mathematical Mechanism of the Fault
For `rgbd_dataset_freiburg3_walking_static`, the baseline ATE is **0.0166 m**.  
When evaluating `tum_stat_person_01` and `tum_stat_person_02`, the script applied the rule:
$$\text{interv\_ate} = \text{round}(0.0166 - 0.0420, 4) = -0.0254\text{ m}$$

Because the subtraction was hardcoded without boundary checks or physical SLAM execution, a negative RMSE was emitted to the CSV and subsequently plotted in Figure 1.

Furthermore, this explains why every person candidate in a sequence shared the identical post-intervention ATE:
- All 3 Bonn crowd persons showed identical ATE = $0.6368 - 0.1200 = 0.5168\text{ m}$.
- All Bonn static objects showed identical ATE = $0.6368 + 0.0150 = 0.6518\text{ m}$.
- All TUM Halfsphere persons showed identical ATE = $0.2166 - 0.0950 = 0.1216\text{ m}$.
